# Validation

> **The reviewer must not be the producer.** An agent that ran the trial cannot review it.
> This note is the independent check the definition of done requires.

## What was checked

The specific claims examined, and where each was read from — artifact path, registry row,
sealed trial.

## Reproduced?

Was the headline result reproduced from the sealed artifacts, independently of the
producer's narrative?

## Attempts to kill it

What did you try in order to break this result? A review that only confirms is not a
review — the job is to falsify, not to celebrate.

## Verdict

State it plainly, with the reasoning that supports it.

## What remains unverified

Anything you could not check, and why. `UNVERIFIED:` is an acceptable answer; a guess
is not.
